# 📱 Control LED & Gears

Project to control LED strips via ESP32 using Bluetooth.

## 🚀 Web Controller (Universal / iOS)
For iPhone users or if you don't want to install the APK, you can use our universal web interface:
👉 **[Open Web Controller](https://DebiTheFox.github.io/ControlAppLedgears/web/)**

> [!IMPORTANT]
> **iOS Users:** Safari does not support Web Bluetooth. To use the controller on an iPhone, please download a Bluetooth-capable browser like **Blueify** or **WebBLE** from the App Store.

## 📥 Download Android App (APK)
Download the latest official APK from the **[Releases](https://github.com/DebiTheFox/ControlAppLedgears/releases)** section.

## ✨ Features (v1.3.0)
- **⚙️ New Settings Activity**: Manage your saved devices and app behavior in a dedicated clean interface.
- **🎨 Advanced Selectors**: Choose between the classic RGB Circle or the new Expert HSV Square.
- **🛡️ Intelligent Connectivity**: High-speed filtering for "ControlLED&Gears" hardware.
- **🕹️ Expert Controls**: Real-time Hue and Lightness bars with CSS-style dynamic transitions.
- **🔄 Smart Updates**: Intelligent version detection and persistent user choices.
- **📱 Responsive Design**: Full support for both Portrait and Landscape modes.

## 🎮 How to use
1. Power on your ESP32 with compatible firmware.
2. Tap the **Bluetooth button** in the app.
3. Select your device (it will be filtered automatically).
4. For the first connection, give your device a custom name (e.g., "Living Room").
5. Enjoy controlling your LED strips! 🦊✨
